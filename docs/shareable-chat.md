# 可分享的沟通会话

品牌方在小程序「项目协作 → 沟通会话」创建会话，点「生成分享卡片」后用微信分享。客服在网页「协作消息」的订单会话右上角点击加号，输入名称创建会话，再生成小程序码发给品牌方。接收者打开微信卡片或扫描小程序码后，小程序保存邀请参数；已有登录态直接加入，否则可使用微信快捷登录，成功后自动返回原邀请并进入聊天。

网页端订单会话与邀请会话共用同一聊天工作台。邀请会话顶部的「创建邀请码」会生成小程序码和对应页面路径。

会话与订单分开保存，沟通阶段不会创建虚假的订单或支付记录。邀请 7 天有效，只允许首位品牌方加入；同一人重复打开邀请幂等，重新生成邀请会使旧邀请失效。服务端保存邀请码哈希，所有消息读写均校验成员身份，消息客户端 ID 防重复。

上线前需要配置：

1. 将 `apps/uni-app/src/manifest.json` 的 `mp-weixin.appid` 改为正式小程序 AppID。
2. 在服务端环境变量配置同一小程序的 `WECHAT_MINI_APP_ID` 和 `WECHAT_MINI_APP_SECRET`，并提供 MySQL。AppSecret 仅保留在服务端。
3. 把正式 HTTPS API 域名加入微信小程序的 `request` 合法域名，并在 `apps/uni-app` 构建时设置 `VITE_API_BASE_URL`。
4. 发布包含 `pages/invite/join` 的小程序版本，再对外发送小程序码。网页生成小程序码依赖微信接口和正式 AppID。

本地测试：`pnpm check:intake`。该脚本创建临时测试账号与会话，验证邀请、独占加入、权限和消息幂等，并清理测试数据。真实微信登录和扫码需要正式小程序配置与真机环境验证。
