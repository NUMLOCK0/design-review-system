# 生图工作台公开商品调研

聊天中的“AI 套图策划”新增公开网页调研。客服手动输入关键词后，服务端调用 Tavily Search API 检索公开页面，将最多 6 个安全 HTTPS 来源、摘要与带来源编号的 AI 归纳保存到当前生图项目的 `workflow.marketResearch`。

启用方式：在运行 `apps/server` 的服务端环境中配置 `TAVILY_API_KEY`，然后重启 API 服务。密钥不得放入 Web/小程序环境变量或浏览器代码。未配置时，页面会提示管理员启用调研服务。

搜索请求只发送客服在调研框中输入的关键词，不会把聊天记录、图片或表单上传给搜索服务。返回摘要是公开市场线索，不是品牌方确认的商品属性；套图 Agent 会把它与客户确认内容分开处理。来源链接由客服核对后再采用。

## 商品调查中的报告与联网资料

商品调查支持读取素材中标为报告的 PDF。每次读取最多 3 份、每份前 8 页；选择了图片理解模型时，最多识别 3 个无文字扫描页。报告摘录及扫描页面会发送给所选模型，识别结果和引用页码都需要人工对照原件。若报告超限、加密、损坏或者扫描页不能识别，调查中会显示相应状态。

联网调查可选用以下任一服务，在 `apps/server` 的运行环境中配置后重启 API：

```env
# Tavily
DESIGN_REFERENCE_PROVIDER=tavily
TAVILY_API_KEY=服务端密钥

# 或使用自建、已启用 JSON 搜索的 SearXNG
# DESIGN_REFERENCE_PROVIDER=searxng
# SEARXNG_BASE_URL=https://your-searxng.example/
```

商品调查只向搜索服务发送商品类型和平台组成的检索词，不发送报告、图片或对话全文。搜索未配置、失败或没有结果时会显示状态并继续调查。所选模型仍会收到本次启用的报告摘录与公开搜索摘要，因此应选择符合资料处理要求的模型服务。
