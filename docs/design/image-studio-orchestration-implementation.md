# 设计总控与后台调度实施记录

更新：2026-10-31。本文件记录实际代码能力，不等于商业上线验收证书。

## 当前接入

### 需求收集、方案确认与画布制作的边界

- 需求表单统一为具体推荐答案卡片加“其他”。只有选择“其他”才展开输入；空的“其他”不能完成必填题，提交保存实际自定义内容，切换选项保留当前自定义草稿。旧的 text/textarea 问题也使用这一交互。
- 对话模型应结合当前项目提供 3 至 5 个具体答案。遗漏选项时由无工具的选项顾问最多补全一次（30 秒请求超时），只能补充原问题的选项；失败保留问题和稳定 ID，以兼容选项降级，不阻断整轮需求收集。

- 新项目先通过表单分轮收集需求。会话摘要按品牌/商品模式保存待答问题与需求完整性确认状态；未回答的必填项不能被模型提前返回的方案覆盖，部分提交与刷新保留稳定的问题 ID。
- 收集完成后先确认需求完整，再整理方案。方案始终为待确认，聊天选择方向不会自动审批；修改方案内容后需重新确认。直接生成方案的旧接口也检查需求收集状态。
- “确认方案”只保存审批结果。“开始制作”才持久化 productionStarts 标记，并创建每张图片对应的一组文本提示词 → 生图节点；图片在原槽位回填，重试不新增重复图文组。
- 方案、分析、调研、提示词任务等中间过程保留在对话和任务记录中，不另铺到画布。实际提交的逐图提示词首次关联任务时同步到文本节点，后续进度刷新保留用户编辑。
- 浏览器验证使用两张独立 Logo 的临时项目：启动前无节点、启动后两组四个节点、刷新后仍为四个节点。运行标记为 testOnly，Worker 不派发模型；验证后删除临时数据与会话文件。
- 空白生图节点显示实际等待原因，包括人工确认、前置任务、派发中和结果加载；后台暂停时明确显示待确认任务，不能把创建占位节点等同于已调用生图。
- 修复内联 SVG 转 PNG 后丢失 OSS 标识的问题：持久化重写继承节点类型与 MIME，将 canonical storageKey 和 PNG MIME 一同回存，保留原 SVG 源码，继续执行服务端归属校验。
- 调度同步使用稳定 JSON 比较，忽略数据库 JSON 字段排序与 undefined 字段；等待确认且内容未变化时不增加项目版本，避免持续触发画布恢复和多窗口保存冲突。
- 确认方案并开始制作后，自动推进生图和模型审稿。品牌规范类人工节点由文本模型生成建议，SVG 类人工节点按 SVG 任务执行；无法自动执行的人工核验节点明确记录为跳过，不能声称已人工检查。旧的等待确认计划可以切换为自动继续，其他项目不会被自动改变。
- 生图调度复用本次运行开始后、相同项目/任务/方案/模型且槽位完整的已有任务；已完成图片必须仍存在于当前项目。明确重试失败项不会被旧任务覆盖。

### 第一阶段：持久化调度

- 已接通运行、任务、事件三张表及启动、列表、事件、确认、取消、重试接口。
- Worker 周期扫描可运行计划；MySQL 命名锁串行处理同一运行；不同 Worker 可恢复中断的扫描。
- 派发复用原有任务创建事务与 Outbox。稳定幂等键覆盖创建任务后、绑定任务前的进程中断。
- 用户明确重试已失败的任务才创建新的调用；图片任务仅重试失败槽位。不确定的派发结果使用原键恢复。
- 执行使用确认时的方案、提示词、模型配置 ID 与 Skill 摘要快照。方案版本变化后停止旧计划后续派发，旧产物保留。
- 正常连接使用 Socket 失效通知；重连读取服务端状态；断线降级刷新。数据库事件提供游标读取。
- 已有项目手动任务流程保留；项目存在活动调度时阻止前端单任务重复执行。

### 第二阶段：专业角色

- 总控对话继续负责需求与任务图规划。
- 注册表映射需求分析、风格探索、逐图提示词、生图、审稿、调研、SVG、交付角色。
- 专业角色复用不同任务处理器和系统指令，尚非相互自由对话的独立自治进程。
- 复用六风格探索、多选/融合、项目记忆和自动 Skill 匹配。
- 提示词任务在后台模式下严格按 slotKey 返回逐图提示词；生成任务接收前置任务结果与已有品牌素材。

### 第三阶段：生图与审稿

- 图片生成继续使用现有队列和槽位，任务结果可恢复到画布。
- 增加 design_review 视觉任务，必须读取实际图片、返回素材 ID 与可见依据。
- 模型审稿结束后自动继续并保留审稿依据；不自动再次扣费生成。
- 支持查看审稿依据、显式重试失败项、停止后续任务。
- 单次审稿最多 12 张；超过时明确失败并要求拆分，不能静默只审部分。

### 第四阶段：搜索和交付

- 参考搜索支持 Tavily 与配置的 SearXNG 实例。未配置时跳过，来源与未知授权标记保留。
- SVG 增加服务端基础结构、安全元素和尺寸校验；明确商标/字体授权仍未核验。
- 交付任务可创建原有成品 ZIP 导出，需用户先选择成品。
- 新增 PSD 图层组装队列与界面：已选图片分别作为位图层，支持位置/尺寸；标题可作为原生文字层。
- PSD 使用 ag-psd 34.1.0，写出合成预览后重新读取验证尺寸、图层数，导出结果放入私有 OSS。
- PSD 不包含自动分割成品图，也不自动推断背景补全；AI 自主规划并分别生成全部图层尚未接入。
- 原生文字图层的字体替换和 Photoshop 首次重绘行为须在实际客户端验证。

## 本地配置

`apps/server/.env`：`IMAGE_STUDIO_ORCHESTRATION_ENABLED=true`。
模板默认关闭。切换后需让 API 与 Worker 都重新加载环境。

SearXNG：设置 `DESIGN_REFERENCE_PROVIDER=searxng` 和 `SEARXNG_BASE_URL`；实例须启用 JSON 与图片搜索。
实现依据：[Search API](https://docs.searxng.org/dev/search_api.html)、[Image Results](https://docs.searxng.org/dev/result_types/main/image.html)。没有代配公共实例。

回退：关闭调度开关前先停止或完成活动调度。关闭开关不会删除任何历史数据；不要在活动运行中直接切换回前端批量执行。
