## 当前可走通的品牌方路径

小程序底部导航与 Web 移动端统一为「首页 / 订单 / 消息 / 我的」。会话和设计成果仍是独立页面，从首页常用功能及业务详情进入，避免将聊天表单误当作整个消息中心。

1. 工作台 → 发布订单 → 填写基本信息、图片规格、设计要求、预算与审核流 → 创建订单。
2. 我的订单 → 搜索或筛选 → 订单详情 → 查看状态与设计进度；在允许的状态下编辑、重新提交、重新发布或关闭。
3. 订单进入协作后，详情可进入会话、需求资料和关联设计稿；消息中心的订单与审核通知可回到对应详情。

## 下一阶段依赖

- 小程序内支付需要适配微信小程序支付方式；现有 `/payments/orders/:id/checkout` 返回扫码付款地址，不能直接作为 `uni.requestPayment` 参数。
- 完整订单闭环还需要设计师申请处理、品牌方邀请、评价和纠纷页面。
- 若要与 Web 移动端角色覆盖一致，还需要独立规划设计师、客服、管理员的小程序登录和导航。
